# Codex fixture record

IronLint v1 does not ship or test a Codex adapter. The JSON files in this
directory are historical, provenance-stamped captures from `codex-cli 0.141.0`.
They document the retired adapter protocol and are not consumed by the v1 test
suite or evidence for current Codex behavior.

See each file's `_provenance` header for its capture details. See the parent
adapter README for instructions that remove an installation owned by an older
IronLint release.
